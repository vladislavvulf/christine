# Christine — корейский алфавит в игре 🐯

**Сайт:** https://christine-korean.vercel.app · **Android:** [скачать APK](https://github.com/vladislavvulf/christine/releases/latest)

Mobile-first веб-приложение для изучения хангыля: уроки-игры, аудирование, мини-игры, сцены в стиле дорам, рейтинг и регистрация.

**Стек:** Next.js 16 (статический экспорт) + React 19 + PHP API (SQLite или MySQL).
**Node.js нужен только для сборки у вас на компьютере.** На хостинг загружается готовая папка `out/`: обычный PHP-хостинг, без Node.js.

---

## 🚀 Деплой на обычный PHP-хостинг (3 шага)

```bash
npm install
npm run build
```

1. После сборки появится папка **`out/`**. В ней уже лежат страницы, скрипты и PHP API (`out/api/`).
2. Загрузите **содержимое** `out/` в корень сайта (`public_html`, `www`, `htdocs`…) по FTP или через файловый менеджер хостинга.
3. Откройте `https://ваш-сайт/api/index.php?action=ping`: должно вернуться `{"ok":true,...}`. Готово!

**Требования к хостингу:** PHP 7.4+ с расширениями `pdo_sqlite` (или `pdo_mysql`) и `mbstring`. Apache (или nginx с правилами ниже).

### Вход через Google (необязательно)
1. Откройте [Google Cloud Console](https://console.cloud.google.com/apis/credentials) → **Create credentials → OAuth client ID** → тип **Web application**.
2. В **Authorized JavaScript origins** добавьте адрес сайта (например `https://christine.ru`, для проверки — `http://localhost:8080`).
3. Скопируйте **Client ID** в `api/config.php` → `'google_client_id' => '…apps.googleusercontent.com'`.

Пересобирать сайт не нужно — кнопка «Продолжить с Google» появится сама. Хостингу нужен доступ в интернет (cURL), чтобы проверять вход у Google.

### База данных
- **По умолчанию SQLite**, ничего настраивать не нужно. Файл базы создастся сам:
  сначала скрипт пробует папку `christine-data/` **уровнем выше** корня сайта (там её не достать из браузера),
  если туда нельзя писать, то `api/data/` (закрыта `.htaccess`).
- Если появляется ошибка про права, создайте папку `api/data` и выставьте права `775`.
- **MySQL:** в `api/config.php` поставьте `'driver' => 'mysql'` и заполните доступы. Таблицы создадутся автоматически.

> ⚠️ При обновлении сайта **не удаляйте** `api/data/` или `christine-data/`: там база пользователей.
> Удобнее всего загружать новую сборку поверх старой. Если меняли `api/config.php` на сервере, не перезаписывайте его.

### Сайт в подпапке (например `https://site.ru/korean/`)
```bash
# Linux/macOS
BASE_PATH=/korean npm run build
# Windows PowerShell
$env:BASE_PATH="/korean"; npm run build
```
И в `out/.htaccess` поправьте строку `ErrorDocument 404 /korean/404.html`.

### nginx
```nginx
location / { try_files $uri $uri/ $uri/index.html =404; }
location ~ ^/api/data/ { deny all; }
location ~ \.php$ { include fastcgi_params; fastcgi_pass unix:/run/php/php-fpm.sock; fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; }
```

## ▲ Деплой на Vercel

На Vercel фронтенд раздаётся как статика, а API работает как Node-функция (`api/main.ts`) с базой Postgres.
Протокол тот же, что у PHP-версии, поэтому фронтенд одинаковый для обоих вариантов.

1. Импортируйте репозиторий на [vercel.com/new](https://vercel.com/new). Настройки сборки уже лежат в `vercel.json`.
2. **Storage → Create Database → Neon (Postgres)** → подключите к проекту. Переменная `DATABASE_URL` появится сама, таблицы создадутся при первом запросе.
3. По желанию: **Settings → Environment Variables → `GOOGLE_CLIENT_ID`** — для входа через Google
   (в Google Cloud добавьте домен `https://<проект>.vercel.app` в Authorized JavaScript origins).

Без базы сайт работает в гостевом режиме: уроки, игры и дорамы доступны, но регистрация и рейтинг — нет.
Проверка API без облака: `npm i --no-save @electric-sql/pglite && npx tsx scripts/test-api.mts`.

## 📱 Android-приложение (APK)

Приложение — Trusted Web Activity: полноэкранный Chrome с сайтом (работают вход через Google, YouTube, микрофон, обновления без переустановки).
APK собирается в облаке GitHub Actions — Android SDK на компьютере не нужен.

1. **Settings → Secrets and variables → Actions**:
   - переменная `TWA_HOST` — домен сайта без `https://` (например `christine-korean.vercel.app`);
   - секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_PASSWORD` — ключ подписи.
2. **Actions → Android APK → Run workflow** (или пуш тега `v1.0.1`). APK и AAB (для Google Play) появятся в **Releases**.
3. Файл `public/.well-known/assetlinks.json` связывает сайт и приложение (без него сверху будет адресная строка).
   Если меняете ключ подписи или имя пакета — обновите в нём `sha256_cert_fingerprints` / `package_name`.

> Ключ подписи (`android/release.keystore` + `android/keystore-info.txt`) в Git не попадает. Сохраните его в надёжном месте:
> без него нельзя выпустить обновление приложения.

## 💻 Локальная разработка

```bash
npm install
npm run api        # PHP API на :8000 (в отдельном терминале)
npm run dev        # Next.js на :3000, запросы /api проксируются на PHP
```

Проверить готовую сборку ровно так, как она будет работать на хостинге:
```bash
npm run build
npm run preview    # http://localhost:8080
```

Другие команды: `npm run typecheck` (проверка типов), `npm run check` (генерирует все уроки и квизы и проверяет, что задания корректны).

### Озвучка
Вся речь — готовые mp3 (≈3,6 тыс. файлов, ~15 МБ в `public/audio/`), записанные нейросетевыми голосами Microsoft (SunHi, InJoon, Hyunsu).
Работает в любом браузере и не зависит от того, есть ли в системе корейский голос. Если добавили слова или реплики — допишите озвучку
(готовые файлы не перегенерируются):

```bash
pip install edge-tts
npm run audio
```
Нужны Python 3 и ffmpeg. Распознавание речи («Повтори») работает в Chrome и Safari.

### Фрагменты из дорам (YouTube)
Клипы лежат в `src/lib/clips.ts` — это официальные ролики каналов tvN, KBS и др., владельцы которых разрешили встраивание.
Субтитры (корейский, транскрипция, перевод, разбор слов) синхронизированы с видео.
**Добавить свой клип:** откройте на сайте `/studio/`, вставьте ссылку, отмечайте реплики во время просмотра — Студия выдаст готовый код.

> В регионах, где YouTube замедлен или заблокирован, видео может не загрузиться. Тогда субтитры, озвучка реплик и квиз продолжают работать.

```
scripts/            postbuild (подготовка out/) и проверка контента
```
